## Three things to get right when quoting this

**The negative claims travel with the affirmative ones.** C6, C7, and C8 are claims, not disclaimers. A summary that keeps the results and drops them is not a shorter version of this study's claim; it is a different and prohibited one.

**Two qualifiers are inseparable from what they qualify, on the same surface — including spoken answers.**

- Wherever the Range B classification is stated together with Range B, the sentence must also say that its `No alert` input comes from a rule query that does not record which index it searched, so Range B's zero-alert observation is not established.
- Wherever the procedure's coverage-dependent branching is shown, the same place must say it was demonstrated by feeding the frozen scorer a counterfactual input — it is not an observation.

**No valid negative was ever observed.** Range A produced `Alert`. The study did not compare two negative outcomes, and no wording may imply that it did.

## What is not here

The judgment *rules* — the plan that fixed required observations, disconfirmation conditions, and over-claim boundaries **before** any hypothesis was judged — live in Kakuriyo, as do the review rounds that rejected the first version of nearly every document in this directory. The claims stand on their own; the process record does not need to be public to make them checkable, because each judgment names the artifacts it read and this kit lets you produce equivalents.
